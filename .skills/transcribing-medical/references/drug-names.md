# Drug Name Reference (excerpt)

A small brand→generic glossary to disambiguate commonly mis-heard medication
names. This is a level-3 resource: it is read on demand, not injected into every
prompt.

| Brand | Generic | Common confusions |
|-------|---------|-------------------|
| Tylenol | acetaminophen | "Tylenol PM" vs plain |
| Advil / Motrin | ibuprofen | dose 200/400/600/800 mg |
| Coumadin | warfarin | sound-alike: Avandia |
| Lasix | furosemide | sound-alike: Losec |
| Glucophage | metformin | extended-release "XR" |
| Zestril / Prinivil | lisinopril | dose 5/10/20/40 mg |
| Norvasc | amlodipine | sound-alike: Navane |
| Synthroid | levothyroxine | micrograms, not mg |

When a dose or drug name is unclear in the audio, transcribe `[inaudible]`
rather than guessing — a wrong dose is a clinical-safety risk.
